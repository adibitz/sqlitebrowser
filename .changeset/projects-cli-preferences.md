'sqliteview': minor
---

Save and open DB Browser for SQLite project files (.sqbpro) with the open tables, their filters and sort, and SQL editors. Command line flags open a database or project (-R read-only, -t table) and run an SQL file (-s, with -q to write and quit). A Preferences dialog (Ctrl+,) for the general, database, data browser, SQL editor and extension settings.
