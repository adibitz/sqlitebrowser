Control SQliteView from Claude Code: turn on the MCP server in Preferences → Claude Code (MCP) and copy the connect command. Claude Code can read the schema and data, open tables with filters, open and run SQL, and edit the database. Its edits stay uncommitted so Revert undoes them, and writing them to disk asks you first. The server listens on this computer only and needs a private token.
